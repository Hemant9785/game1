# Play Store Launch Checklist

- Final package name confirmed before first production release
- Release keystore created and backed up securely
- Play App Signing enabled
- Privacy policy hosted on a public HTTPS URL
- Data Safety form completed accurately
- Internal testing track verified on a Play-installed build
- `local.properties` points at the free production validator
- Privacy policy hosted on a no-cost service such as GitHub Pages
- `ENABLE_HTTP_LOGGING=false` for release
- `bundleRelease` built successfully
- Store listing assets, screenshots, description, support email, and category added
